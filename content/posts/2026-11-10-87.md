## 設置、配線する
まずは2台のPCと4台のルータで配線をする

![image|480](/images/2026/hcxof24u.webp)

## それぞれのルータにG0/1に10.0.12.x/30を設定する
RIPで利用するネットワーク、IPアドレスを設定していく

ルータのターミナルで以下のコマンドを実行するか、設定のG0/1にネットワークを10.0.12.0/30とIPアドレス10.0.12.1を指定（ipコマンドの方がこれに関しては楽だと思われる）
```
ip address 1 10.0.12.1 255.255.255.252
```

![image|480](/images/2026/s2u2v8yc.webp)

![image|480](/images/2026/b95w9m5y.webp)

### ルーター 2
```
ip address 0 10.0.12.2 255.255.255.252
ip address 1 10.0.23.1 255.255.255.252
```


### ルーター 3
```
ip address 0 10.0.23.2 255.255.255.252
ip address 1 10.0.34.1 255.255.255.252
```


### ルーター 4
```
ip address 0 10.0.34.2 255.255.255.252
```

![image|480](/images/2026/24kbmud4.webp)


## ルータをRIPとして設定する

### ルータ 1
```
router rip
network 192.168.1.0
network 10.0.12.0
```

router ripでRIP機能を有効にし、network x.x.x.0 (/24の場合) でRIPにネットワークを追加する

### ルータ 2
```
router rip
network 10.0.12.0
network 10.0.23.0
```

### ルータ 3
```
router rip
network 10.0.23.0
network 10.0.34.0
```

![image|480](/images/2026/c4qdvepd.webp)

### ルータ 4
```
router rip
network 10.0.34.0
network 192.168.2.0
```

## テストする
PC-1で実行してみる。

```
ping 192.168.2.10
```

![image|480](/images/2026/zdlme4jo.webp)

経路情報を取得する

```
traceroute 192.168.2.10
```

![image|480](/images/2026/xnhzevcw.webp)

ルーティング情報を確認、show ip routeをルータで実行してみる
```
show ip route
```
