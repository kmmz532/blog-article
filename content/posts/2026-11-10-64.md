## nix-setup-systemdを入れる
nix-setup-systemdは、DebianやUbuntuなどでパッケージマネージャNixをマルチユーザモードでセットアップできるパッケージであるやうだ。

実は一番上にある画像はよろしくなくて `sudo apt install nix` で実行してnix-setup-systemdを入れてくれたが、正しくは

```bash
sudo apt install nix-setup-systemd
```

だそうだ。

{{< link-card url="https://www.reddit.com/r/debian/comments/1jabrct/guide_install_the_nix_package_manager_on_debian/?tl=ja" >}}

## ユーザをグループnix-usersに追加

```bash
sudo adduser $(whoami) nix-users
```

## Nixチャネルを追加して更新する
Nixにおけるチャネルとは「パッケージ取得先」だそうだ。aptでいうソースみたいなものだろうか

```bash
nix-channel --add https://nixos.org/channels/nixpkgs-unstable
nix-channel --update
```

## パッケージを入れる
emacsやgit、nodejsでも入れておく

```bash
# 従来
nix-env -iA nixpkgs.emacs
nix-env -iA nixpkgs.git
nix-env -iA nixpkgs.nodejs

# 推奨 (下記のNix Flakes を利用するをしてから)
nix profile install nixpkgs#emacs
nix profile install nixpkgs#git
nix profile install nixpkgs#nodejs
```

NixOSであれば `configuration.nix` があるそう。また、nixではHome Managerでユーザ環境の管理ができるみたい。

{{< link-card url="https://zenn.dev/kuu/articles/20250204_introduce-home-manager" >}}

## Nix Flakes を利用する
`~/.config/nix/nix.conf`

```conf
experimental-features = nix-command flakes
```

home-manager を導入

```bash
nix run home-manager/master -- init --switch
```
