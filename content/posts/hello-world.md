本日、10月29日、かみみずブログを開設しました！！

# 技術構成
サーバの運用コストを考えずにブログ運用をしたい！！ということで、、、
こんな感じの技術スタックになりました。

- GitHub Pages - サイト公開先
- Hugo - 静的サイトジェネレータ
- JavaScript - 管理ツールの実装
- GitHub API - 管理ツールで利用するAPI
- GitHub Actions - ビルド、デプロイ

SSGだけどCMSのように使いたい！だからJSとGH APIを用いてWebページから編集できるしくみにしました。
Git管理しつつ、SSGで静的ウェブ配信できて、Web上から編集もできるようなものです。

これで自宅じゃなくてもいつでもGitが使えない環境下でも編集できますし、ブログの管理がかなり楽になるはず...！

外部サイトに書いた記事とか全部移すのも大変なので外部リンクとしてそのまま登録できる仕組みもつくりました。

# 目的
ただ単にブログサイトをつくっただけでは終わらしたくないので、実際に運用しちゃいます。
日々の考えややったことなど日記として残しておきたいと思います！

考えを残すことで後々、その先で参考にできたらなという思いです。
実はInstagramに写真をバンバン投げているのも、日々の行った場所を記録したいという思いがあります。
ただ、写真としては記録できても考えは残りません、だから考えも残したいというのでブログを置いちゃいました。
